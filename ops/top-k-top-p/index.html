Top-k / Top-p

top_k_top_p

截断采样，控制生成多样性与可靠性的旋钮

它在做什么，为什么需要

Top-k 只保留概率最高的 k 个 token；Top-p（核采样）按概率从高到低累加，一旦超过 p 就截断 —— 后者会随分布形状自适应调整候选集大小。两者常一起用。调它们就是在"敢不敢冒险"之间选位置：k=1 即贪心解码。

参考实现

top_k_top_p · 教学精简版python
def top_k_top_p(logits, k=0, p=1.0):
    if k > 0:
        idx = logits.topk(k, -1).values[..., -1:] 
        logits = logits.masked_fill(logits < idx, float("-inf"))
    if p < 1.0:
        s, i = torch.sort(logits, descending=True)
        cum = torch.cumsum(torch.softmax(s, -1), -1)
        drop = cum - torch.softmax(s, -1) > p
        logits = logits.masked_fill(i * 0 + drop, float("-inf"))
    return logits

这是为讲清原理写的精简版，去掉了 dtype / layout / 融合算子等工程细节； 生产环境请直接用 PyTorch 原生实现（它走的是 fused kernel）。
