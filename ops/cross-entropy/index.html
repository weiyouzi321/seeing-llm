Cross Entropy

cross_entropy

语言模型的训练目标，从 logits 到 loss

它在做什么，为什么需要

对正确 token 的预测概率取负对数。模型越确信答案正确，loss 越接近 0；猜错且很自信时 loss 会非常大。注意 PyTorch 的 cross_entropy 内部已包含 log_softmax，所以传进去的应是未归一化的 logits。

亲手调一调

下面这个是可交互的 —— 拖滑块、点按钮，看数字怎么动。

loss = −log p(正确 token)

这条曲线决定了训练的动力：模型越确信答案，loss 越接近 0；一旦猜错还很自信， loss 会飞到天上去 —— 这就是为什么梯度容易炸。

参考实现

cross_entropy · 教学精简版python
def cross_entropy(logits, target):
    logp = torch.log_softmax(logits, dim=-1)
    return -logp.gather(-1, target.unsqueeze(-1)).mean()

这是为讲清原理写的精简版，去掉了 dtype / layout / 融合算子等工程细节； 生产环境请直接用 PyTorch 原生实现（它走的是 fused kernel）。
