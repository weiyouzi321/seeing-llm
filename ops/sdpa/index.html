SDPA

scaled_dot_product_attention

缩放点积注意力，一切注意力的公共内核

它在做什么，为什么需要

softmax(QKᵀ/√d)·V。除以 √d 是必须的：不缩放的话，点积的方差会随维度 d 线性增长，softmax 会被推进梯度极小的饱和区，训练直接停滞。GQA、MLA、线性注意力都是在改这个式子的某一部分，而不是推翻它。

参考实现

scaled_dot_product_attention · 教学精简版python
def sdpa(Q, K, V, mask=None):
    d = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / (d ** 0.5)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))
    return torch.softmax(scores, -1) @ V

这是为讲清原理写的精简版，去掉了 dtype / layout / 融合算子等工程细节； 生产环境请直接用 PyTorch 原生实现（它走的是 fused kernel）。
