ReLU

relu

最简单的非线性，却是稀疏激活的起点

它在做什么，为什么需要

把负数压成 0、正数原样通过。没有它，无论堆多少层线性变换，整体仍等价于一层线性变换 —— 非线性才是"深"度有意义的前提。它同时让一部分神经元输出恰好为 0，这是 MoE 之外最常见的稀疏性来源。

激活函数对比 · x ∈ [−4, 4]

ReLU 的价值不在「曲线好看」，而在它把一半输入压成精确的 0 —— 这是 MoE 之外最常见的稀疏来源。后面的 GELU / SiLU 都在试图缓解它「一刀切」的问题。

ReLU负数硬截断为 0 —— 一半神经元直接静默，这是最廉价的稀疏
GELU「按概率随机置零」的平滑版，GPT / BERT 系列默认
SiLUx·σ(x)，0 附近平滑且允许小负值，LLaMA / Qwen 在用

标准正态输入下 ReLU 输出为 0 的比例 ≈ 50%。Kimi K3 的 FFN 用 SiTU-GLU 取代朴素 ReLU， 正是为了在保留稀疏的同时拿到平滑梯度。

1输出[B, L, d]

参考实现

relu · 教学精简版python
def relu(x):
    return torch.maximum(x, torch.zeros_like(x))

这是为讲清原理写的精简版，去掉了 dtype / layout / 融合算子等工程细节； 生产环境请直接用 PyTorch 原生实现（它走的是 fused kernel）。
