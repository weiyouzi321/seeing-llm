Linear Attention

linear_attention

K3 的 KDA 与 Qwen3.8 的 Gated DeltaNet 的共同底色

它在做什么，为什么需要

把 softmax(QKᵀ)V 换成 Q(KᵀV)：先算 KᵀV（一个 d×d 的矩阵，与 L 无关），再让 Q 去乘它。复杂度从 O(L²d) 降到 O(Ld²)，且可以写成递推形式 —— 每读一个 token 更新一次状态，KV Cache 彻底不需要了。代价是丢掉了 softmax 的锐利聚焦能力，所以要靠稀疏/门控等机制补强。

参考实现

linear_attention · 教学精简版python
def linear_attention(Q, K, V):
    # 不构造 L×L 矩阵，先聚合 KᵀV
    KV = K.transpose(-2, -1) @ V      # [B, H, dh, dh]
    return Q @ KV                     # [B, H, L, dh]

# 递推形式：状态随 token 累积，显存与 L 无关
def recurrent_step(q_t, k_t, v_t, S):
    S = S + torch.einsum("hd,he->de", k_t, v_t)
    return torch.einsum("hd,de->he", q_t, S), S

这是为讲清原理写的精简版，去掉了 dtype / layout / 融合算子等工程细节； 生产环境请直接用 PyTorch 原生实现（它走的是 fused kernel）。
