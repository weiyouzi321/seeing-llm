Linear Regression

linear_regression

最小二乘闭式解，理解 autograd 的最小例子

它在做什么，为什么需要

y ≈ Xw，最小化平方误差。它有闭式解 w = (XᵀX)⁻¹Xᵀy，不需要迭代 —— 正因为有解析答案，它常被用来验证自己手写的反向传播是否正确：梯度下降收敛到的 w 应当逼近这个闭式解。

张量形状链路

0X[N, d]
1y[N]
2w[d]

参考实现

linear_regression · 教学精简版python
# 闭式解（正规方程）
def linear_regression(X, y):
    return torch.linalg.solve(X.T @ X, X.T @ y)

这是为讲清原理写的精简版，去掉了 dtype / layout / 融合算子等工程细节； 生产环境请直接用 PyTorch 原生实现（它走的是 fused kernel）。
