Softmax

softmax

把 logits 压成概率；数值稳定版要减去 max

它在做什么，为什么需要

指数归一化，让一组分数变成和为 1 的概率。工程上有两个必须知道的点：一是要减去 max 再取 exp，否则 exp(1000) 直接溢出成 inf；二是它有个温度参数 T —— T 越小分布越尖锐（越贪心），T 越大越平缓（越随机），这是所有采样策略的旋钮。

参考实现

softmax · 教学精简版python
def softmax(x, dim=-1, T=1.0):
    z = x / T
    z = z - z.max(dim=dim, keepdim=True).values  # 防溢出
    e = torch.exp(z)
    return e / e.sum(dim=dim, keepdim=True)

这是为讲清原理写的精简版，去掉了 dtype / layout / 融合算子等工程细节； 生产环境请直接用 PyTorch 原生实现（它走的是 fused kernel）。
