Embedding

embedding

查表取词向量；160K 词表下这层参数不容小觑

它在做什么，为什么需要

本质是一张 [词表大小, 隐藏维] 的表格，按 token id 取行。Kimi K3 词表 160K、隐藏维 7168，仅这一层就有约 11 亿参数。很多模型还会让输入 embedding 与输出 softmax 权重共享（tied embedding）来省参数。

亲手调一调

下面这个是可交互的 —— 拖滑块、点按钮，看数字怎么动。

token id
[B, L]
→
权重表
[V, d]
→
输出
[B, L, d]

参考实现

embedding · 教学精简版python
def embedding(ids, W):
    # W: [V, d]，按 id 取行
    return W[ids]

这是为讲清原理写的精简版，去掉了 dtype / layout / 融合算子等工程细节； 生产环境请直接用 PyTorch 原生实现（它走的是 fused kernel）。
