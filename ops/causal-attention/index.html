Causal Attention

causal_attention

加下三角掩码，保证只看得见过去

它在做什么，为什么需要

在 scores 上加一个下三角掩码，把"未来"位置填成 -inf，softmax 后自然变成 0。没有它，训练时模型会偷看答案，推理时却看不到 —— 训练/推理不一致，生成质量崩掉。注意是"因果掩码"而非"padding 掩码"，两者用途不同。

因果掩码 ≠ padding 掩码：前者防止偷看未来（自回归必须）， 后者屏蔽补齐的无效位置（batch 内变长必须）。两者可以同时叠加在同一个 scores 上。

参考实现

causal_attention · 教学精简版python
def causal_mask(L):
    return torch.tril(torch.ones(L, L)).bool()

def causal_attention(Q, K, V):
    return sdpa(Q, K, V, mask=causal_mask(Q.size(-2)))

这是为讲清原理写的精简版，去掉了 dtype / layout / 融合算子等工程细节； 生产环境请直接用 PyTorch 原生实现（它走的是 fused kernel）。
